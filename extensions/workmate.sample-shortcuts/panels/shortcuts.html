Shortcuts & tips快捷键与小技巧

A quick reference for getting around CSBU WorkMate faster.帮助你更快上手 CSBU WorkMate 的速查表。

⌘/Ctrl means ⌘ on macOS and Ctrl on Windows and Linux.在 macOS 上是 ⌘，在 Windows 和 Linux 上是 Ctrl。

Get around导航与会话

  • Open the command palette打开命令面板
    ⌘/Ctrl+K
  • New conversation Desktop桌面版新建会话
    ⌘/Ctrl+T
  • Next conversation Desktop桌面版切换到下一个会话
    Ctrl+Tab
  • Previous conversation Desktop桌面版切换到上一个会话 Uses Ctrl on every platform, including macOS.在所有平台（包括 macOS）上都使用 Ctrl 键。
    Ctrl+Shift+Tab

Layout界面布局

  • Show or hide the sidebar Desktop桌面版显示 / 隐藏侧边栏
    ⌘/Ctrl+B
  • Show or hide the workspace panel Desktop桌面版显示 / 隐藏工作区面板
    ⌘/Ctrl+L

Preview & editing预览与编辑

  • Save the open file保存当前文件 In the preview editor.在预览编辑器中。
    ⌘/Ctrl+S
  • Close the preview tab关闭当前预览标签 Only while focus is inside the preview panel.仅当焦点位于预览面板内时生效。
    ⌘/Ctrl+W

Message box消息输入框

  • Recall an earlier message调出之前发送的消息 Press ↑ with the cursor on the first line; ↓ moves forward.光标在第一行时按 ↑；按 ↓ 向后翻。
    ↑/↓
  • Leave message history退出历史消息浏览 Restores the draft you were typing.恢复你正在输入的草稿。
    Esc
  • Commit with the typed message用已输入的说明提交 In the commit box on the Changes tab.在“变更”标签的提交框中。
    ⌘/Ctrl+Enter

Quick tips小技巧

  • Type @ in the message box to reference a file or another session.在消息输入框中输入 @ 即可引用文件或其他会话。
  • Find plugin panels under Plugin panels in the sidebar; opening one shows it next to your preview and files.在侧边栏的 插件面板 中可以找到插件面板；打开后会显示在预览和文件旁边。
  • Panels run in a sandbox: this page is plain HTML and CSS, with no scripts and no network access.面板运行在沙箱中：本页只有 HTML 和 CSS，没有脚本，也不能访问网络。
Rows marked Desktop桌面版 work in the desktop app. 标有 Desktop桌面版 的项目仅在桌面版中可用。
