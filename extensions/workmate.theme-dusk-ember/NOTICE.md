This theme pack contains colour values derived from "Dusk & Ember Themes" (orca-dusk-ember 1.1.0),
https://github.com/stablyai/orca-plugins/tree/main/plugins/dusk-ember at commit
4589eb93e28d8a4e4fdd3a77670297da804e7abe.
The values were converted into CSS custom properties for CSBU WorkMate; terminal colours, syntax
colours and images were not used.

Upstream git blob SHAs at that commit (plugin-level files we vendor):
- LICENSE fbf46fc17dacb1f65e03e2b6290eb53ba94b149d
- themes/dusk.json 99b70bf0ec0313b27ac6e5be5c7233b45dcbd9ae
- themes/ember.json 099b9cd51a00d43f0dac8828af69207bd8015739

The cover SVG and the token-to-WorkMate mapping are original CSBU WorkMate work.
Orca's cover.png, dusk.png and ember.png were not copied.
